# magixs

A Python library for modeling the Marshall Grazing Incidence X-ray
Spectrometer (MaGIXS), a sounding rocket experiment led by the
NASA Marshall Space Flight Center which captures spatially resolved spectra
of the solar corona in soft X-rays, from 6 to 24 Å.

The optical system is modeled using [`optika`](https://optika.readthedocs.io)
and [`named-arrays`](https://named-arrays.readthedocs.io).
So far the package is limited to the first flight, on 2021 July 30,
and it is built from the published descriptions of the instrument.

This package is not a product of the MaGIXS team.
