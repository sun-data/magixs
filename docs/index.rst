Introduction
============

The Marshall Grazing Incidence X-ray Spectrometer (MaGIXS) is a sounding
rocket experiment led by the NASA Marshall Space Flight Center which captures
spatially resolved spectra of the solar corona in soft X-rays,
from 6 to 24 Angstroms.

This Python package models the optical system of MaGIXS using :mod:`optika`
and :mod:`named_arrays`.
It is built from the published descriptions of the instrument,
and it is not a product of the MaGIXS team.

Installation
============

This package is not yet published to PyPI,
but it can be installed from GitHub using pip.

.. code-block::

    pip install git+https://github.com/sun-data/magixs.git
